 Note: 
 Also in APIUtils use commonJS export syntax:

 module.exports = { APIUtils };

 CommonJS is Node.js’s traditional module system. It lets one file load another with require() and share code with module.exports.

In your test, this:
const { APIUtils } = require('./utils/APIUtils');

loads the helper module. For that to work, APIUtils.js exports the class like this:
module.exports = { APIUtils };

The newer JavaScript module system, ES modules, uses import and export instead. 
The key is to use matching import/export styles. 
Your project is configured for CommonJS with "type": "commonjs" in package.json.

//package.json
`package.json` is the project’s Node.js manifest. It tells npm and Node.js what the project needs and how to interpret it.

In this project, it:
- Lists development dependencies, including Playwright, so they can be installed with `npm install`.
- Sets `"type": "commonjs"`, which makes Node.js treat `.js` files as CommonJS modules (`require` / `module.exports`).
- Provides project metadata such as its name and version.

It can also define scripts such as `"test": "playwright test"`; this project currently has no scripts defined. 
The accompanying `package-lock.json` records the specific dependency versions installed.
