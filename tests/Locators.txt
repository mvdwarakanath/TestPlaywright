Locators are used to identify html component on a webpage

Id attribute
css --> tagname#id  ; e.g input#id OR #id

name
css --> [name='username']

class attributes --> tagname.class   ; e.g input.form-control ; e.g. select.form-control // makes it unique

css on any attribute 
css --> tagname[attribute='value']       ### tagname is optional

Write CSS with traversing from Parent to child e.g. locator(".user__name [type='text']")
css -> parenttagname >> childtagname
